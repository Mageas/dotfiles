### VSCode for Wayland

To launch VSCode in Wayland mode, copy and modify the desktop file:
```BASH
cp /usr/share/applications/code.desktop ~/.local/share/applications/
```

Then, edit the `Exec` line in `~/.local/share/applications/code.desktop`:
```DESKTOP
Exec=/usr/share/code/code --enable-features=UseOzonePlatform,WaylandWindowDecorations --ozone-platform-hint=auto --unity-launch %F
```

### Installing selectdefaultapplication

Dependencies: `git`, `qt5-qtbase-devel`, `make`, `gcc-c++`

```BASH
git clone https://github.com/sandsmark/selectdefaultapplication.git
cd selectdefaultapplication

qmake-qt5
make

sudo cp selectdefaultapplication /usr/local/bin/
sudo cp selectdefaultapplication.desktop /usr/share/applications/

sudo mkdir -p /usr/share/pixmaps
sudo cp selectdefaultapplication.png /usr/share/pixmaps/
sudo update-desktop-database /usr/share/applications/
```

### Configuration files

Since Hyprland 0.55 the `hyprlang` (`.conf`) format is deprecated in favor of Lua.
The config now lives in `~/.config/hypr/hyprland.lua`, and the other files are pulled
in with `require()`. See the [wiki](https://wiki.hypr.land/Configuring/Start/).

- `hyprland.lua` – Main settings, animations, visual effects
- `binds.lua` – Keybindings
- `programs.lua` – Application settings
- `startup.lua` – Autostart programs
- `window_rules.lua` – Window rules
- `workspaces.lua` – Workspace setup
- `hypridle.conf` – Idle management (screen lock, DPMS) — hypridle still uses `hyprlang`

Colors are generated by matugen into `~/.config/hypr/styles/colors.lua` (a Lua module
returning a table); `hyprland.lua` loads it with a fallback if it hasn't been generated yet.

`.luarc.json` points the Lua LSP at the stubs shipped in `/usr/share/hypr/stubs` for
autocompletion of the `hl.*` API.

### Setup

**Install Rofi themes:**

```BASH
cd /tmp
git clone --depth=1 https://github.com/adi1090x/rofi.git
mkdir -p ~/.local/share/fonts
cp rofi/fonts/*.ttf ~/.local/share/fonts/
```

**Generate the first color scheme:**

```BASH
matugen image ~/.local/wallpapers/blue-forest.png
```

**Configure VSCode keyring:**

In `~/.config/Code/argv.json`, add:
```
"password-store": "gnome-libsecret"
```
